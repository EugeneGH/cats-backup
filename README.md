# Резервное копирование картинок с котами

Курсовая работа группы AIE-8.

Программа получает от пользователя текст и сохраняет картинку
с котом и этой подписью на Яндекс.Диск.

## Возможности

- Создание папки AIE-8 на Яндекс.Диске.
- Загрузка картинки с cataas.com напрямую на Диск.
- Использование введённого текста как имени файла.
- Сохранение имени и размера загруженного файла в result.json.
- Логирование этапов выполнения.

Картинки на компьютер не сохраняются.
Существующие файлы на Диске не перезаписываются.
result.json содержит сведения о последней успешной загрузке.
Размер файла указан в байтах.

## Установка

Требуется Python 3.10 или новее.

Установите зависимости:

python -m pip install -r requirements.txt

## Запуск

python Main.py

Введите текст для картинки, затем OAuth-токен Яндекс.Диска.
При вводе токена символы не отображаются.

Токен используется только во время работы программы.
Его не нужно записывать в исходный код или загружать в репозиторий.

## Используемые сервисы

- https://cataas.com/
- https://yandex.ru/dev/disk/rest/
